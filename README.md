# Ad Block Scripts for Loon

A collection of ad-blocking plugins for various apps, organized by app.

## Directory Structure
| Folder | App |
|---|---|
| `ths/` | Tonghuashun |

## How to Use
1. Open Loon > Config > Plugins > tap "+"
2. Select "Download from URL"
3. Paste the `.plugin` Raw URL for the app you want
4. Done. JS scripts are auto-fetched.

## Adding New Apps
Create a new folder with the app's short name, and follow the same file structure.
